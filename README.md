# Birthday surprise

A one-page Next.js birthday site in a lavender theme: a cover page that counts
down to midnight, a real-time 3D cake (three.js) whose candles you blow out with
your microphone, a "Happy 21st" moment with confetti, and a WhatsApp "request
your gift" button in the corner.

## 1. Configure

Everything personal lives in `.env` (restart the dev server after editing):

| Variable | What it does |
| --- | --- |
| `NEXT_PUBLIC_BIRTHDAY_NAME` | The name shown everywhere |
| `NEXT_PUBLIC_BIRTHDAY_DATE` | Date of birth, `YYYY-MM-DD`. Drives the age and the countdown |
| `NEXT_PUBLIC_CAKE_NAME` | Pet name piped on the cake board ("Happy Birthday Rimmi"); defaults to `Rimmi`, empty = use the name |
| `NEXT_PUBLIC_WHATSAPP_NUMBER` | International format, no `+`. `0717697494` → `94717697494` |
| `NEXT_PUBLIC_WHATSAPP_MESSAGE` | Pre-filled text of the gift request |
| `NEXT_PUBLIC_SIGNATURE`, `NEXT_PUBLIC_WISH` | The small lines of wording |

`?name=` and `?date=` in the URL override the env values, which is handy for testing.

## 2. Add the photos

Drop real files into `public/images` — each one replaces its placeholder
automatically:

- `hero.jpg` — the photo on the cover page
- `cake.png` — **optional**: a cut-out cake photo (transparent background,
  square, unlit candles) replaces the 3D cake. Line the flames up with
  `CAKE.ring` in `lib/config.js`.

The 3D cake is built in code (`lib/cake3d.js`): drag sideways to spin it, drag
up/down to look at the top. It has number candles for the age ("21") in
lilac-striped wax, and "Happy Birthday <name>" piped on the board. (Only the
digits 1 and 2 are drawn so far; any other age falls back to a few twisted
candles.) The 3D code starts loading while the cover is open and fades in when
ready. Phones without WebGL get the drawn SVG cake instead
(`components/CakeArt.jsx`). Add `?quality=low` to the URL to switch off the
soft crease shading on a slow phone (it also switches itself off if a phone
struggles), or `?quality=high` to force it on.

**Blowing:** a soft breath only makes the flames flicker; a strong breath held
for about a second (`BLOW.HOLD_MS`) puts them out. Little bubbles over the
cake cheer her on ("A little harder!", "Keep going!", "Almost there!",
"Don't stop!") — wording in `components/BlowCheer.jsx`, timing in
`lib/cheer.js`. When they go out: one confetti burst with the "Happy 21st,
Birthday <name>" moment, then back to the cake page.

The birthday song is a built-in music box (`lib/song.js`), no file needed. The
lyrics above the cake light up word by word in time with it. It plays above the
pitch range the microphone listens to, so it never blows the candles out itself.

**Optional video:** put a clip at `public/videos/happy-birthday.mp4` and it plays
after the candles go out instead of the built-in "Happy 21st" animation.

**Before sending the link:** set `COVER.allowEarlyOpen` to `false` in
`lib/config.js`. While it's `true` (for testing) the "Open your surprise" button
works before midnight.

Music is optional too. With nothing in `public/audio` the page is silent; add
`happy-birthday.mp3`, `party.mp3`, `whoosh.mp3` or `cheer.mp3` and they start
playing (the mute button only appears once something loads).

Placeholders are generated by `npm run assets`.

## 3. Run

```bash
npm run dev
```

- On this machine: http://localhost:3000
- From a phone on the same Wi-Fi: `http://<your-ip>:3000`

## Opening it on a phone

The page itself works over plain http, but **browsers only allow microphone
access on https or localhost**, so on `http://192.168.1.247:3000` the candles
fall back to a tap button. To get the real blow-out on a phone, pick one:

1. **Run the dev server over https** (easiest):

```bash
npm run dev:https
```

Then open `https://<your-ip>:3000` and accept the self-signed certificate warning.

2. **Allow the origin in Chrome** on the phone: `chrome://flags/#unsafely-treat-insecure-origin-as-secure`,
   add `http://192.168.1.247:3000`, enable, relaunch.

3. **Deploy it** (Vercel, Netlify, …) — any real https URL works.

If the LAN page fails to load assets at all, add your IP to `allowedDevOrigins`
in `next.config.mjs`.

## Testing shortcuts

| URL | Shows |
| --- | --- |
| `/` | Cover page with the countdown (button unlocks at midnight) |
| `/?preview=countdown` | Forces the countdown on the cover |
| `/?skip=1` | Cover page already unlocked |
| `/?name=Ann&date=2001-04-09` | Overrides the env values |

## Tuning the blow detection

`BLOW` in `lib/config.js`. Lower `THRESHOLD` if it's too hard to blow the
candles out, raise it if background noise sets them off. A tap fallback appears
after 18 seconds, and immediately if the mic is unavailable.

## Layout

```
app/              routes, metadata, fonts
components/       cover, countdown, cake (3D + SVG fallback), "Happy 21st" burst
hooks/            useBlowDetection — the Web Audio FFT analysis
lib/              config, age maths, audio, confetti, cake3d (three.js scene)
styles/           base (tokens, backdrop) · screens · cake · ui
scripts/          placeholder image generator
```
